# オンガチャ 記事LP(UGC風)

「オンガチャって怪しいの?」という不安ワードに答える、個人ブログ風の記事LPです。

## ファイル構成

- `index.html` — ページ本体(このファイルをそのままドメインに配置すればOK)
- `images/` — 記事内で使用している画像一式

## デプロイ時の確認事項

- GTM(`GTM-T2KC22JV`)を埋め込み済みです。実際のドメインに設置後、GTM側でタグの発火を確認してください。
- 記事内のCTAリンク先は `https://on-gacha.com/?aff=1O4rZ5Bh` になっています。計測用パラメータが正しいか確認してください。
- `<meta name="robots" content="noindex, nofollow">` を設定しています。検索結果に出したくない場合はこのままで、SEO流入も狙う場合はこの行を削除してください。
- 特定商取引法・プライバシーポリシーへのリンクは、オンガチャ公式サイト(`company.on-gacha.com`)のページに向けています。

## 公開前に必ず確認してほしいこと

記事内の「口コミ」「当選報告」に使用しているスクリーンショットは、実在の個人によるX/Threadsの投稿です。本人の許諾を得ずに広告(集客目的のLP)に転載すると、著作権・肖像権上のリスクがあります。公開前に、投稿者への許諾取得、または実在の投稿を参考にした創作コンテンツへの差し替えを検討してください。
